# Security Policy

## Reporting security issues

Please do not report security vulnerabilities through public GitHub issues.

To report a security issue, contact:

```text id="dc8u57"
security@snoooz.ai
```

If this address is not monitored yet, replace it with the correct Snoooz security contact before publishing this repository.

## What to include

Please include:

* A description of the issue
* Steps to reproduce
* Affected endpoint or tool
* Potential impact
* Any relevant logs or screenshots
* Your contact information

## Sensitive data

Do not include:

* OAuth tokens
* Refresh tokens
* Mailbox credentials
* API keys
* SMTP/IMAP passwords
* Customer email contents
* Private user data
