# Quickstart

This guide shows how to connect Snoooz MCP to an MCP-compatible AI assistant.

## 1. Choose your region

Use the endpoint that matches where you sign in to Snoooz.

| Snoooz app URL             | MCP server URL                 |
| -------------------------- | ------------------------------ |
| `https://app.snoooz.ai`    | `https://app.snoooz.ai/mcp`    |
| `https://app-eu.snoooz.ai` | `https://app-eu.snoooz.ai/mcp` |

## 2. Add Snoooz as a custom MCP server

In your MCP-compatible client, add a custom remote MCP server.

Use one of:

```text
https://app.snoooz.ai/mcp
```

or:

```text
https://app-eu.snoooz.ai/mcp
```

## 3. Sign in with Snoooz

The client will redirect you to Snoooz.

Sign in, then approve the requested permissions.

## 4. Try a prompt

Try prompts like:

```text
List my Snoooz workspaces and tell me which one is selected.

Show my current Snoooz rules in plain English.

Create a draft-only AI rule for sales leads and preview it before enabling automatic sends.

Configure this rule to follow up after 3 days, with a maximum of 2 follow-ups.
```

## 5. Preview before relying on automation

Before enabling automatic sending, use Snoooz preview tools to test how rules match and what reply Snoooz would generate.

Recommended prompts:

```text
Simulate which Snoooz rule would match this email.

Preview the reply Snoooz would generate for this email.
```
