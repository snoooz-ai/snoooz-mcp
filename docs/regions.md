# Regions

Snoooz has separate MCP endpoints for Global / US and EU customers.

## Global / US

Use this endpoint if your Snoooz account is hosted at:

```text
https://app.snoooz.ai
```

MCP server URL:

```text
https://app.snoooz.ai/mcp
```

## EU

Use this endpoint if your Snoooz account is hosted at:

```text
https://app-eu.snoooz.ai
```

MCP server URL:

```text
https://app-eu.snoooz.ai/mcp
```

## Which endpoint should I use?

Use the same region where you normally sign in to Snoooz.

Using the wrong region may cause sign-in, workspace, or authorization issues.
