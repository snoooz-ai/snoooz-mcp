# Snoooz MCP

Snoooz MCP lets AI assistants and app builders configure Snoooz email automation in natural language.

Use Snoooz MCP with MCP-compatible tools such as ChatGPT, Claude, Lovable, Replit, Cursor, and other AI apps to create rules, configure automatic follow-ups, train knowledge, preview replies, and troubleshoot mailbox automation.

## MCP server URLs

Choose the endpoint that matches your Snoooz account region.

| Region | MCP server URL |
|---|---|
| Global / US | `https://app.snoooz.ai/mcp` |
| EU | `https://app-eu.snoooz.ai/mcp` |

If you sign in to Snoooz at `app.snoooz.ai`, use the Global / US endpoint.

If you sign in to Snoooz at `app-eu.snoooz.ai`, use the EU endpoint.

## What you can do

With Snoooz MCP, AI assistants can help you:

- Create and update email automation rules
- Configure AI reply rules
- Configure draft-only rules for human review
- Configure automatic follow-ups
- Preview how Snoooz would respond to a test email
- Simulate which rule would match an email
- Train Snoooz from FAQs, PDFs, websites, CSVs, and help-center content
- Manage categories, labels, and templates
- Check mailbox connection and automation health
- Troubleshoot why Snoooz did or did not respond
